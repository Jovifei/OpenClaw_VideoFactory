# Pink Pig mascot director

Primary source repository:

`https://github.com/Jovifei/ian-fenzhu-illustrations`

Codex should inspect that repository first. If it already contains a reusable skill or asset pipeline, adapt it. If not, extract the role definition, visual language, or reusable assets into this local skill.

## Goals

- Increase brand recognition.
- Add fun without distracting from technical clarity.
- Reuse the mascot across embedded-engineering videos and AI-hot-topic videos.

## Minimum deliverables

1. Stable role definition.
2. 5–8 reusable expressions or poses.
3. Placement modes: corner mark, knowledge-point helper, transition bumper, ending signature.

## Rules

- Do not block the main render path if a mascot asset fails; fall back to a simpler pose or no mascot.
- Never let the mascot cover critical code, diagrams, subtitles, or protocol bytes.
- Prefer deterministic 2D assets over regenerating the character every time.
- If AI generation is used to expand the pack, review it against the canonical role definition first.


## Canonical character DNA from the source repository

- low-saturation mist-pink solid body;
- small round snout, dot eyes, small ears and small wings;
- calm, serious, slightly clumsy;
- works by measuring, repairing, carrying, wiring, welding, sorting and modifying;
- symbolizes: ordinary things can grow their own wings after careful modification.

Every video keeps a small brand signature. Active participation is optional and must serve the core idea.
