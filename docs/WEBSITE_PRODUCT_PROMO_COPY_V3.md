## 朋友圈 / 小红书配图文案

找机位、看天气、挑时间，先放在一张地图上。

逐星把逐小时预报、暗夜选址、连续观测窗口和云海条件图放到同一个工作台里。

云海条件图展示高分候选与模式层位关系；条件指数用于比较，不等于现场概率。

它不是“必出片”按钮，也不替代现场判断。出发前先看一眼，到了现场再复核天气、道路与安全。
